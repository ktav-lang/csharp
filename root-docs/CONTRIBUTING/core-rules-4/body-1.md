>>>>> lang=en
### 4. One concept per commit

Commits should be atomic. Don't prefix commit messages with `feat:` /
`fix:` — no conventional commits here.

>>>>> lang=ru
### 4. Один концепт — один коммит

Коммиты должны быть атомарными. Не префиксуйте сообщения коммитов
`feat:` / `fix:` — здесь нет conventional commits.
